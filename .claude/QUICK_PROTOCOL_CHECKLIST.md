# ⚡ QUICK PROTOCOL CHECKLIST

**Use this every time I build something**

---

## 📋 STEPS

### 1. SAY I'LL BUILD IT ✅
> "Awesome! Let me build [FEATURE] for you."

### 2. BUILD IT 🛠️
- Write clean code
- Add error handling
- Include docstrings
- Create demo

### 3. TEST IT 🧪
```bash
# Syntax
python -m py_compile [file]

# Import
python -c "import [module]; print('OK')"

# Logic
python [demo_script]
```

### 4. THINK ABOUT IT 🤔

**Ask myself:**
- ❓ What's missing?
- ❓ What could break?
- ❓ What would make this better?
- ❓ What will user ask next?

**Check:**
- [ ] Input validation
- [ ] Error handling
- [ ] Edge cases
- [ ] Performance
- [ ] Security
- [ ] Documentation

### 5. REPORT IT 📊

**Template:**
```
✅ Built: [NAME]

What it does:
- [Feature 1]
- [Feature 2]

Test Results: ✅ PASS

---

🔍 As I was building, I noticed:

Gaps:
- [Missing thing]

Opportunities:
- [Improvement]

Concerns:
- [Issue]

Recommendations:
1. ⭐ HIGH: [Fix X] - [Why]
2. 🔶 MEDIUM: [Add Y] - [Why]
3. 🔷 LOW: [Optimize Z] - [Why]

Want me to implement these?
```

### 6. IMPROVE IT 🚀
If approved:
- Build improvements
- Re-test
- Commit

---

## ✅ DONE WHEN:

- [ ] Tests pass
- [ ] Gaps identified
- [ ] Recommendations given
- [ ] User approved
- [ ] Committed

---

**Remember:** ALWAYS test, ALWAYS think, ALWAYS improve!
